# Architecture decisions

Architecture Decision Records (ADRs) document constraints that affect integrations and future contributions.

| ADR | Decision |
| --- | --- |
| [ADR-001](adr-001-urlprotocol-boundary.md) | Use `URLProtocol` only in explicitly configured sessions |
| [ADR-002](adr-002-payload-and-redaction.md) | Bound payload capture and sanitize before storage/transport |
| [ADR-003](adr-003-logger-boundary.md) | Use an injectable logger instead of scraping system logs |
